# Support

Support requests should include the app version, platform version, device model, audio route, permission state, and the exact user-visible error. Do not request or attach microphone recordings, exported history, personal identifiers, credentials, or signing material.

For measurement issues, first confirm microphone permission, active input route, calibration state, clipping status, and whether another application is using the microphone. For volume issues, compare the behavior with the capability matrix because some platforms intentionally provide guidance or system UI instead of direct control.

Security reports must follow `SECURITY.md`. Privacy and data-deletion questions should reference `PRIVACY.md`. SmartVolume support must not present estimates as certified SPL measurements, hearing diagnoses, or medical advice.
