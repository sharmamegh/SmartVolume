# Platform matrix

The native platform family is pinned as one compatibility unit:

- React 19.1.4
- React Native 0.81.6 for Android and iOS
- React Native Windows 0.81.27
- React Native macOS 0.81.9
- Node.js 22.14 or newer for desktop tooling

Upgrade the matrix together. Before merging an upgrade, regenerate a temporary reference shell, review native template changes, run every CI host, and repeat physical-device microphone, lifecycle, volume, storage, and accessibility tests.
