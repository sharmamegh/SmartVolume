# Commercial readiness

The local-first baseline includes privacy-first capture, bounded storage, export and deletion, accessibility semantics, deterministic tests, platform capability handling, and multi-host CI.

Before public distribution, the product owner must provide final branding, support contacts, store listings, signing identities, a jurisdiction-reviewed privacy policy, license review, incident response ownership, customer support processes, release rollback, and physical-device validation.

Accounts, billing, analytics, advertising, remote configuration, cloud sync, and diagnostic vendors are not enabled. Adding any of them requires consent design, retention rules, deletion and export support, threat modeling, entitlement recovery, and store disclosure updates.
